# 03: Orçado x realizado de obras

**Mês 4 do plano (40h, junto com estatística).** Entrega: dashboard de orçado x realizado.

É o projeto que mais aproveita sua experiência com construtoras e o ERP UAU. Use **dados fictícios** que imitem a estrutura real: obras, etapas, insumos, orçamento previsto e custo realizado por mês. Nunca use dados reais de clientes.

Ideias de indicadores: desvio de custo por etapa, curva S de execução e top 10 insumos com maior estouro.
