# 04: Análise de dados em Python

**Mês 5 do plano (40h).** Entrega: uma análise em Python publicada no GitHub.

## Como começar

Para abrir o Jupyter:

```
jupyter lab
```

Para testar a conexão com o PostgreSQL:

```
python 04-python/teste_conexao.py
```

O teste lê as credenciais do arquivo `.env` na raiz do projeto. Esse arquivo fica só no seu PC e nunca vai para o GitHub.
